# Limitations and publication blockers

**NOT READY for public comparative rankings.** The software can collect and explain pilot evidence, but the following remain unresolved:

- No independent human ground-truth approvals; all 174 scenario hashes need review. Automated reference solvability is insufficient.
- Ten new merchant clients plus the legacy client share infrastructure and many task compositions. Fifteen independent implementations and 60–100 independently prepared tasks remain research targets, not achieved claims. Current statistical analysis conservatively uses one shared-engine cluster.
- No genuinely unseen, independently authored/reviewed sealed final corpus. The vault and one-use reservation workflow exist; corpus acquisition/execution remains pending. Existing holdouts are regression cases.
- Exact TinyClick weights unavailable in the identified repository. Hybrid cannot pass genuine dual-inference verification until this is resolved. MAI/UI-Venus have identified provenance but no configured local weights/real smoke on this machine.
- CUA cold/warm smoke verifies real loading and valid output, not accuracy or end-to-end success. No expensive full model comparisons were run during framework development.
- No official payment sandbox credentials. Full Stripe/Shopify/Razorpay/Cashfree browser payment/3DS/UPI validation pending. Read-only object checks and optional hosted-page inspection do not establish fidelity.
- Predominantly English synthetic tasks, assisted controllers, shared protocol and server state; no production-provider, native mobile-app or real-money claims.
- Stage observations are server-acknowledged behavioral proxies. S01 does not measure cognition; some completion intervals are zero due to simultaneous observation.
- Bootstrap intervals require sufficient independent clusters and do not fix biased sampling or multiple comparison problems. Missing comparable method/provider coverage suppresses winner labels.
- Cost estimates exclude unreported local operating costs. Remote model identity attestation and remote loading/warm timing remain unavailable.
- The repository still needs an owner-selected code/data redistribution license; model license metadata does not license the benchmark code.
- Final repetition counts need a preregistered pilot variance study. Independent external reproduction and controlled-public-run review have not occurred.

The readiness endpoint reports missing gates. It does not call reference success or five configured endpoints a validated benchmark.
